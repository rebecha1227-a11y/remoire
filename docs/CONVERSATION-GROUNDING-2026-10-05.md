## 根因与本地修复

1. 自主生成把正文独白、think 标签和 API reasoning_content 合并，还会从 think 中提取 message。改为只解析正文；隐藏推理与工具协议不作为角色独白或推送。空正文兜底及中文改写同样只取正文。保留中文角色表达，移除英文格式标题，不改写历史日志。
2. 生活事实规则原先偏向过去记忆。新增 grounding.md，并在实际聊天/自主 system prompt 中加载：生活细节仅用明确依据，感官描写也不能虚构用户环境；区分发送时间、事件时间、当前时间，跟随用户切换话题。
3. 最近消息原先只有相对间隔。新增北京时间发送标记，保持用户原文不变；已存事件日期随记忆注入，意识层标为主观感受而非确认事实。不迁移或推断历史事件日期。
4. 提取器原先允许推测 confidence=0.7+ 自动入库。现在还需 explicit 与能匹配用户原话的 evidence_quote，缺失或推测只进入候选。未更改表结构、手动确认或 MCP remember 行为；引文匹配不是语义真实性证明，仍依赖模型正确理解引文，不宣称消除幻觉。
5. 新自主日志 detail 记录实际成功槽位与配置 model_id，便于后续追查；历史缺失字段不回填猜测。
