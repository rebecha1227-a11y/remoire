## 当前未解决的问题

### ⚠️ 底部黑色条（高优先）
iPhone 15 standalone PWA 模式下，底部导航栏下面仍有一条黑色区域（约 30-40px，home indicator 区域）。

**已尝试过的方案（都失败了）：**
1. `height: 100dvh` → 不够高，底部露黑
2. `height: 100%` → app 只显示 1/3 高度（height chain 断了）
3. `position: fixed; inset: 0` → 底部仍然露黑（iOS PWA fixed bottom:0 不到物理屏幕底部）
4. `visualViewport` API 同步高度 → 键盘弹出时容器缩小，出现更大的黑块
5. `.r-nav::after` 伪元素向下延伸 100px → 被父级 `overflow: hidden` 裁掉
6. `document.body.style.background = palette.navBg` → **最新方案，等待静儿确认效果**

**下一步建议**：
- 如果 body 背景色方案仍然有黑色，可能是因为 iOS 在 safe area 下方用的是 `theme-color`（manifest.json 里是 `#574337`），或者系统级渲染。尝试：
  - 改 `manifest.json` 的 `background_color` 和 `theme_color` 为动态匹配的暖色
  - 或在 `<meta name="theme-color">` 上动态设置
  - 或给 `html` 元素也设置同样的背景色
  - 或彻底放弃 `overflow: hidden`，在更底层解决

### ⚠️ 键盘弹出时布局
iOS PWA 键盘弹出时，`position: fixed` 容器可能仍有问题。之前用 `visualViewport` 修过但引入了更大的黑块。当前方案是不处理（保持 fixed inset:0），键盘弹出时依赖 iOS 默认行为推动内容。需要在真机上确认。

### Nginx 配置
- 位置：`/etc/nginx/sites-available/remoire`
- 关键 MCP 块：
```nginx
location /mcp {
    proxy_pass http://127.0.0.1:8001/mcp;
    proxy_set_header Host 127.0.0.1:8001;  # 必须是这个，不能是 $host
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 600s;
    proxy_http_version 1.1;
```
