## 关键决策及原因

| 决策 | 原因 |
|---|---|
| iMessage 走现有 `stream_chat`，不 fork 聊天逻辑 | 关系连续：同一记忆、同一关系档案 |
| 小邮差 Node 进程不读库、不调模型 | 密钥与业务分离；Python 单点鉴权 |
| 生产 Node 22 独立安装，不改系统 Node | spectrum-ts 依赖；降低 systemd 风险 |
| 不从 Git 覆盖生产 DB / 身份文件 | 生产记忆 960+、消息 6000+；只迁 Photon 账号行 |
| 换模型只改槽位，不为 Claude 写死协议分支 | 静儿明确要求；`llm.py` 已按模型名选 Anthropic/OpenAI |
| 第一版只做文字 | 计划范围；富媒体需 Spectrum 类型 + 存储 + UI |
| Uranus 作**实现参考**，不整仓 fork | Remoire 不商用；静儿已征得 Uranus 开发者许可。读 `Uranus_Imessage` 学消息类型/卡片/接法，代码仍写进 Remoire 自己的桥与 `stream_chat`，记忆只走 SQLite |
| 去掉用户可见与 LLM 历史的「来自 xxx」前缀 | 静儿要求不要任何这种标注；iMessage 入口仍用一句 system 动态说明 |
| 本机停小邮差 | 与生产抢同一条 Photon 线路 |

## 坑和注意事项

1. **两台小邮差不能同时在线**（本机 + 生产），否则 Photon 线路行为异常。
2. **`IMESSAGE_BRIDGE_TOKEN`** 在生产 `.env`；**勿**提交 `.env`、Photon Secret、桥接 token。
3. 本地开发：`SESSION_COOKIE_SECURE=false` + 同时开 8000 与 5173；`unset APP_PASSWORD_HASH` 且 `MODEL_SECRET_ENCRYPTION_REQUIRED=false` 若本地无 Fernet 钥匙。
4. 生产 `remoire` 用 `/opt/remoire/venvs/2fe26c9/bin/python`；文档里旧的 `backend/venv` 路径可能过时。
5. 日志隐私：`log_privacy.py` 只打 `error_type`，排 LLM 失败要靠复现或临时非生产日志。
6. **`docs/记忆系统架构与AI搭建指南.md`** 在工作区显示为删除，副本在 `教程文档/记忆系统架构与AI搭建指南.md`；**未**作为本次 commit 的删除项处理。
7. 主动消息走 iMessage 时仍生成完整上下文；投递失败会 fallback Web Push（见 `nudge_service`）。
8. 生产 daily 模型以**生产库 `model_slots`** 为准；本机改槽不会自动同步生产。

| 能力 | Uranus/Photon 侧要点 | Remoire 建议落点 | 复杂度 |
|---|---|---|---|
| **语音条** | 收 audio attachment；可 TTS 回发 | `messages` 增媒体字段或附件表；`imessage_bridge` 传二进制/URL；聊天页播放器；可选 TTS 槽 | 高 |
| **现画的图 / 图片** | 收 image；生成图再发 | 已有聊天 image 部分可复用；iMessage 入站接 image → 存盘 → `stream_chat` vision；出站 upload + send | 中高 |
| **表情包 / sticker** | sticker 类型 | 解析 sticker id/资产；模型侧用简短文字描述；出站需 Spectrum sticker API 调研 | 中 |
| **撤回** | unsend / retract 事件 | inbox 表增事件类型；对话里标记撤回；避免模型继续引用 | 中 |
| **贴表情（Tapback）** | reaction 事件 | 入站 reaction → 可选写入 messages 或 side table；出站 `react` | 中 |
| **链接卡片**（含 **Apple Music**） | rich link / preview | 入站解析 URL metadata；UI 卡片组件；Apple Music 可能需 oEmbed/OG 或手动解析 | 中高 |
| **转账卡片** | **视觉卡片，不过账** | 模板气泡 + 固定 layout；模型 tool 或结构化输出；**不做真支付** | 中（产品+UI） |
| **特效 / 全屏动画** | iMessage 特效 | Spectrum 是否暴露需查 Photon 文档；可能 P3 | 高/不确定 |
| **瑞幸/麦当劳点单** | Uranus 接第三方 API | 独立集成，非 Photon 自带；P3 | 高 |

**推荐实现顺序（富媒体）**

1. **图片**（与现有聊天图片对齐）→ 2. **语音条（收 + 可选 TTS 发）** → 3. **链接预览卡片（含 Apple Music URL）** → 4. **Tapback / 撤回** → 5. **Sticker** → 6. **转账样式卡片** → 7. 特效 / 外卖。

每做一类：更新 `test_imessage.py`、假邮差单测、设置页说明、发布记录；**真实 Photon 类型**需静儿真机验。
