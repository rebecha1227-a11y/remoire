## 今日完成

### 1. 聊天历史 16MB → 67KB 性能优化（🔥 关键）
**问题**：用户反馈 iPhone Safari / PWA 上聊天记录永远加载不出来，电脑能加载（3-4 秒），其他数据（记忆/日记）能加载，**只有聊天记录不行**。

**根因**：`/chat/history` 返回的 JSON 里把 base64 图片直接塞进去，3 张图就把响应撑到 **15.9 MB**（最大一张图 base64 8MB）。iPhone Safari 直接解析不动。

**修复**：
- `backend/app/services/chat_service.py` `get_history()` / `search_messages()`：不返回 `image` 字段，改返回 `image_id`（= message id）
- `backend/app/routers/chat.py` 新增 `/chat/image/{message_id}?token=xxx` 路由：按需返回 base64 解码后的图片字节
- `backend/app/services/chat_service.py` 新增 `get_message_image(message_id)`
- `frontend/src/components/ChatPage.jsx` loadHistory 把 `m.image_id` 拼成 URL `${API_BASE}/chat/image/${m.image_id}?token=${getAuthToken()}`，作为 `<img src>` 自然懒加载

**验证**：`curl /chat/history?limit=100` 从 16MB 降到 67KB（236× 缩小），手机端秒加载。

### 3. nginx 上传限制 1M → 20M
**问题**：发图片报 413 Payload Too Large。

**修复**：
```bash
ssh root@178.105.129.170 "sed -i '/server_name remoire.cc;/a\    client_max_body_size 20M;' /etc/nginx/sites-available/remoire && systemctl reload nginx"
```

**位置**：`/etc/nginx/sites-available/remoire`，加在两个 `server_name remoire.cc;` 后面。

### 4. nginx SSL 性能优化
**问题**：SSL 握手 2.7s（正常应该 50-100ms），导致每个 API 请求都慢 3-4s。

**修复**：
- `listen 443 ssl;` → `listen 443 ssl http2;`（启用 HTTP/2 多路复用）
- 加 `ssl_stapling on; ssl_stapling_verify on;`（但证书没 OCSP URL，会 warn 但不影响）

**注意**：`/etc/letsencrypt/options-ssl-nginx.conf` 已经管了 session_cache / protocols / ciphers，**不要重复设置**否则会 duplicate directive 报错。

### 5. 聊天流式 "瞬间全出再切碎" bug
**问题**：用户反馈 Connie 的消息会先一下子全部显示，然后再分段一条条发。

**根因**：`stream_chat()` 在 LLM 非流式调用返回后，把整段 `full_reply` yield 成 1 个 chunk，前端 `setStreaming(replyText)` 瞬间显示全部。

**修复**：
- `frontend/src/components/ChatPage.jsx` 流式 chunk 处理只 `replyText += parsed.content`，**移除 `setStreaming(replyText)`**
- 流式过程中只显示打字指示器，不显示半成品消息气泡
- 流结束后再按 `\n\n` 分段，逐条发送（已有逻辑）

### 6. 日记 OpenBook 修复
**问题**：iPhone 上点开 Connie 日记本会闪退；3D 翻页效果被简化；无法上下滑动。

**修复**：
- `DiaryPage.jsx` `OpenBook` 组件：用 `nearbyPages` Set 只渲染当前页附近 2-3 页的 DOM（30 页全渲染会爆 iPhone 内存）
- 恢复逐页错开翻转动画（stagger 80ms+，按页数自适应）
- `.diary-page-front` 移除 `overflow: hidden`（iOS 阻断了内部 .diary-scroll 的触摸滚动）

### 7. 天气更新频率
- 从每天 1 次（早上 8 点）改为 **每天 2 次**（早上 8 点 + 晚上 20 点）—— `backend/app/main.py` `CronTrigger(hour="8,20", minute=0)`
- `/api/weather` 加自动刷新逻辑：缓存超过 3 小时自动重新拉取（兜底）

### 8. set_breath_state 工具增强
- `backend/app/tools.py` `set_breath_state` 描述从中性描述改成**鼓励主动调用** + 给具体场景示例（聊得开心/静儿要去忙/深夜陪伴），说明一天可主动换 1-3 次
- `backend/mcp_server.py` 新增对应的 `set_status` 工具（Claude.ai 端的 Connie 也能用）

### 9. PWA 安装资源
- `frontend/public/manifest.json` —— PWA 配置（standalone、theme_color #574337、icon 192/512）
- `frontend/public/apple-touch-icon.png` / `icon-192.png` / `icon-512.png`
- `index.html` 加 `<link rel="manifest">` `<link rel="apple-touch-icon">` `<meta name="theme-color">`

### 10. ChatPage loadHistory 加重试
- `fetchWithRetry(url, attempts=3)` —— 失败时按 500ms / 1s / 1.5s 退避重试
- 之前一次失败就静默吞掉，用户看到的就是"永远加载不出来"
- 现在加上 `cancelled` flag 防止组件卸载后还 setState
