## 踩过的坑（今天新增）

### 1. XHS 的 cookie-banner-overlay 遮挡
小红书首页有 cookie 弹窗遮罩层，Playwright 的 `click()` 会被拦截报 "intercepts pointer events"。
**解法**：`page.evaluate('document.querySelector(".cookie-banner-overlay")?.remove()')`

### 2. Twitter 反自动化检测极强
从 VPS IP 用 headless Chrome 访问 x.com/i/flow/login：
- JS 经常加载失败（只剩 `failedScript` hidden input）
- 即使加载成功，Next 按钮点击不推进页面
- `--disable-blink-features=AutomationControlled` + 隐藏 `webdriver` 均无效
- **结论**：不要继续用脚本硬刚 Twitter 登录，改用 cookie 导入方案

### 3. XHS 安全二维码1分钟过期
二维码有效期极短。之前用 SCP 传截图太慢（传输+显示 > 1分钟）。
**解法**：截图直接保存到 nginx 静态文件目录 `/opt/remoire/frontend/dist/`，通过 URL 即时访问。

### 4. Playwright persistent context 锁定 profile
一个 browser profile 同时只能被一个 Playwright 进程使用。如果前一个脚本没正常关闭，后面的会卡住或拿到空白页。
**解法**：启动新脚本前先 `pkill -f "python.*xhs"` 杀掉旧进程。

### 5. SSH heredoc 内嵌 Python 引号问题
在 `ssh ... "python3 -c '...'"` 里写多行 Python 代码，单引号/双引号嵌套极易出错（JS 字符串尤其容易 SyntaxError）。
**解法**：写成 `.py` 文件 SCP 到 VPS 再执行，不要在 SSH 命令里内联 Python。
