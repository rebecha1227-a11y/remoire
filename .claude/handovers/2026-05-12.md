## 关键决策及原因

| 决策 | 原因 |
|---|---|
| 自动日记不强制每天写 | 静儿明确说不想把这件事变成任务，应该让 Connie 自己决定情感浓度够不够、想不想写 |
| 日记用 `extended_thinking=False` | glm-5.1 模型开 thinking 时会把思考链混入输出内容 |
| 气泡尾巴用 div 遮挡法而非 SVG | SVG 尾巴形状不好看，静儿明确拒绝；遮挡法在纯色背景下效果好 |
| 自定义背景图存 localStorage（data URL） | 纯前端方案，不需要后端存储；缺点是大图会占 localStorage 空间，但短期够用 |
| 底部导航选中态用 `--text-deep` 而非 `--accent` | `--accent` (#7C6350) 和 `--text-secondary` (#72665C) 太接近，换成 `--text-deep` (#574337) vs `--text-tertiary` (#AEA49A) 对比更强 |

## 坑和注意事项

- **气泡尾巴的技术限制**：当前实现是用「气泡色方块 + 背景色遮挡块」叠出弧形。纯色背景 OK，图片背景下遮挡块颜色无法匹配，所以图片背景时只能隐藏尾巴。如果未来要图片背景也有尾巴，需要用 CSS `mask` / `clip-path` 重新实现（不要用 SVG path，静儿不喜欢）
- **自定义背景图 localStorage 大小**：data URL 存 localStorage 会很大（一张照片可能 1-5MB），localStorage 上限一般 5-10MB。如果用户上传超大图会存不下。未来应该考虑压缩或用 IndexedDB
- **CLAUDE.md 色值速查表过时**：`--bubble-send` 已改为 `#7C6350`，但 CLAUDE.md 里还写着 `#C8B49E`，下次顺手更新
- **日记模型依赖**：自动日记用的是 `daily` 槽位的模型（当前 glm-5.1），不同模型的 prompt 遵从度差异大，换模型时要重新测试日记质量
