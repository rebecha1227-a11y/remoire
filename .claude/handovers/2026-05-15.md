## 本日完成

### 1. 记忆宫殿组件（MemoryPalace.jsx）

**新建** `frontend/src/components/MemoryPalace.jsx`（约 650 行），完整的记忆管理 UI：

- **宫殿首页**：总记忆数 + 2×2 四层卡片（核心/长期/短期/意识）+ 热力图日历 + 候选审核区

- **层详情页**：搜索 + 按类型筛选（事实/事件/未完成/日期）+ 按时间或权重排序 + 移动到其他层 + 删除
- **日期记忆页**：点击热力图某天查看当天所有记忆
- **候选审核**：显示待审核记忆，"记住"/"不要"操作

**数据修复**：
- 热力图之前全空白——后端返回 `[{date, count}]` 数组，前端当 `{day: count}` 对象用，已修复解析逻辑
- 层详情进去白屏——`data.data` 是 `{items, total}` 不是数组，已改为 `data.data?.items || []`
- 标签不显示——后端字段名是 `tags` 不是 `tags_json`，已修正

**UsPage 入口**：记忆宫殿卡片替换旧"记忆摘要"假数据区，显示总条数 + 最新记忆预览。

### 3. display_mode 持久化（分条/整条发送）

**问题**：切换到"整条发送"后刷新页面，所有历史消息都变成整条显示。

**修复**：
- 数据库 `messages` 表新增 `display_mode TEXT DEFAULT 'split'`
- `save_message()` 新增 `display_mode` 参数
- `get_history()` 返回 `display_mode` 字段
- 前端 `fetchReply()` 发送时带 `reply_style` 参数
- 后端 `stream_chat()` 接收 `reply_style` 并存入 AI 回复
- 前端 `loadHistory()` 按每条消息自己的 `display_mode` 渲染，不再用全局设置

**涉及文件**：`chat.py`（router）、`chat_service.py`、`ChatPage.jsx`

### 4. Thinking 泄露修复

**问题**：某些模型输出 `<thinking>...</thinking>` 标签（不是 `<think>`），内容直接混进聊天气泡。

**修复**：
- 流式路径：`<think>` 和 `<thinking>` 两种开闭标签都处理
- 非流式路径：用正则 `<(?:thinking|think)>.*?</(?:thinking|think)>` 提取并剥离

**涉及文件**：`backend/app/services/chat_service.py`

### 5. 备注修改通知修复

**问题**：修改 Connie 的备注后，Connie 看不到改名消息（原型有此功能，前端迁移时丢失）。

**修复**：
- `SettingsSheet` 新增 `onRename` 回调 + `prevNameRef` 追踪旧名
- `ChatPage` 添加 `handleRename()` → 插入系统消息 + `fetchReply()`
- Header 内联编辑也触发 `handleRename`

**涉及文件**：`frontend/src/components/ChatPage.jsx`

### 6. 图片粘贴
