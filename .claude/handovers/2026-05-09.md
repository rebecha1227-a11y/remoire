### Phase A2 — 聊天页面增强

**执行顺序：先 A2-1 图片发送 → A2-2 模型预设 → A2-3 思考链**

### Phase A2-1 — 图片发送
1. **ChatPage + 号面板**：「图片」按钮点击 → 调用 `<input type="file" accept="image/*">` 选择图片
2. **图片预览**：选中后在输入框上方显示缩略图预览，可取消
3. **发送**：图片 base64 编码随消息一起发到后端（或 multipart upload）
4. **后端**：接收图片，如果当前模型支持 vision 则作为 image content 传给 LLM，否则提示不支持
5. **气泡展示**：用户发送的图片消息在气泡里显示图片

### Phase A2-2 — 模型预设系统
1. **后端新增 `/api/settings/model-presets` 路由**：CRUD 模型预设（每个预设包含：昵称、api_key、base_url、model_name、provider）
2. **后端新增 `/api/settings/model-presets/{id}/models` 路由**：填完 base_url + api_key 后自动拉取可用模型列表（调 `/v1/models`）
3. **后端新增 `/api/settings/slots` 路由**：存取三槽位配置（daily / deep / backend），每个槽位关联多个预设，标记哪个是当前选中
4. **重构 ModelSettings（SettingsSubPages.jsx）**：
   - 上半部分：模型预设库管理（添加/编辑/删除预设，填 api_key + base_url 后自动拉取模型列表，给预设起昵称）
   - 下半部分：三槽位配置，每个槽位下拉选择已有预设，可添加多个，选中标记当前使用
   - 每个槽位可开关 Extended Thinking
5. **后端 `chat_service.py` / `llm.py`**：发送消息时读取当前槽位 + 选中预设的配置调用对应模型

### Phase A2-3 — 聊天输入栏模型指示器 + 思考链
1. **ChatPage 输入框右侧**：新增模型指示器按钮，显示当前模型名 + 模式（日常/深度）+ Extended Thinking 状态
2. **点击展开选择器**：可切换日常陪伴 / 深度时刻模式，在当前模式的预设列表中切换模型，开关 Extended Thinking

4. **后端 `chat_service.py`**：如果 Extended Thinking 开启，请求时传 `thinking` 参数，SSE 流中返回 thinking 内容（新增 `type: 'thinking'` chunk）
