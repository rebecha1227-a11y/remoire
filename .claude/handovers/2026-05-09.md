# HANDOVER — 2026-05-09

## 项目概览
Remoire 是两人专属 AI 陪伴 PWA（FastAPI 后端 + React CDN 原型前端），Phase 1 后端核心已跑通。

## 本日完成

### 日记互动系统
- `diary_interactions` 表加 `seen_by_connie` / `seen_by_jinger` 字段，兼容旧库自动 ALTER
- 日记互动通知改未读机制：`list_recent_notifications_for_connie()` 只拿 `seen_by_connie=0`，拿完标记已读
- 活动流按 interaction `created_at` 排序（前后端）
- 降低自动评论机械感：写日记不再立刻强制生成 Connie 评论，普通留言只在"值得回应"时自动回

### Connie 解锁决策
- 聊天 prompt 构建时先跑 `decide_unlock_requests(limit=3)`
- `POST /api/diary/unlock-decisions` 可手动触发
- 同意后永久解锁；拒绝记录 `unlock_rejected`

### Connie 读静儿日记 + 猜密码
- 新增 `read_jinger_diary` 工具：Connie 可读静儿的日记列表和正文
- 上锁日记只显示标题，需要用 `try_unlock_diary` 猜 PIN 才能看内容
- 猜密码有次数限制（每篇最多 3 次），猜不到可以在动态里留言问
- 原有 `read_diary` 只读 Connie 自己的日记，功能不变

### 时间感知
- 对话历史注入时间间隔标记：两条消息间隔 ≥30 分钟自动插入"（过了 X 小时）""（第二天了）"等
- 新增 `get_current_time` 工具，Connie 可主动查当前时间
- 系统 prompt 已有 `【当前时间】` 块（每次用户发消息时更新）

### 工具按需加载（省 token）
- 工具从全量加载改为按需选择：
  - **基础组**（每次都带）：remember, search_memories, leave_note, get_current_time, write_diary
  - **日记组**（提到日记关键词或有日记通知时才带）：read_diary, read_jinger_diary, try_unlock_diary, reply_diary_interaction, respond_diary_unlock
- `select_tools(user_message, has_diary_notifications)` 根据消息内容选工具
- 普通聊天从 10 个工具定义降到 5 个

### 气泡尾巴
- iMessage 风格 div cutaway 尾巴持续调优
- 当前状态：色块 `borderTopLeftRadius: '18px 10px'` 配合气泡底角 6px，接缝基本消除但仍有微小凸起
- 静儿决定暂时不再调，等以后有精力再优化

### 其他
- `.gitignore` 加了 `.claude/worktrees/` 和 `.playwright-mcp/`
- 修复 `write_diary` 分支被误删的 bug（编辑时误吞了 `elif`）
