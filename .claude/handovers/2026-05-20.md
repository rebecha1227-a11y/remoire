### 2. 情感标注系统（Russell 情感模型）

**之前的问题**：所有记忆的 `valence`（情感正负）和 `arousal`（情绪强度）都是 0。打分公式里的情感加权形同虚设。

**解决方案**：
- 新记忆写入时，LLM 自动标注 valence（0~1）和 arousal（0~1）
- 旧记忆批量回填

**改了什么**：
- `backend/app/prompts/tagging.md`：新增 valence/arousal 输出字段 + 详细评分指引
  - valence：0=极度消极，0.5=中性，1=极度积极
  - arousal：0=完全平静，1=极度强烈
  - 纯事实类记忆（职业、偏好）：valence=0.5, arousal=0.0
- `backend/app/services/memory_service.py`：`extract_candidates()` 解析 LLM 输出中的 valence/arousal
- `backend/app/routers/memory.py`：新增 `POST /api/memory/backfill-emotions` 批量回填接口
- `memory_service.py` 里新增 `backfill_emotions()` 函数，用 LLM 分批标注

**数据**：307/317 条记忆已标注情感（10 条在回填时被 digest 删了所以没标到，不影响）。

### 3. 双通道检索（关键词 + 语义，合并去重）

**之前**：只用语义搜索。但纯语义有时会漏掉精确匹配——比如搜"法语"，语义上可能觉得"韩语"也很近，反而把精确结果挤掉了。

**现在**：两个通道并行，取每条记忆在两个通道中的最高分。

**Channel A（关键词精确匹配）**：
- tag 命中：+0.4 / 个
- 关键词出现在内容中：+0.3 / 个
- 完整 query 出现在内容中：+0.8

**Channel B（语义相似度）**：
- 查询语句生成 embedding → 和所有记忆的 embedding 做余弦相似度
- 阈值 > 0.2 才入选

**合并**：`score = max(keyword_score, semantic_score)`

**最终排序公式**：
```
final_score = score × layer_weight × (1 + arousal × 0.3) × memory_weight
```
- layer_weight：core=1.0, long=0.9, short=0.7, consciousness=0.6
- 已解决的任务打 0.3 倍惩罚
- 40% 概率随机浮现一条旧记忆（模拟"突然想起来"）
- 短期/意识层记忆被触发 ≥3 次自动晋升为长期

**VPS 验证**：用三个查询测试通过——"法语"（精确命中）、"好累不想上班"（语义联想到工作相关记忆）、"生日"（精确+语义都能找到）。

### 4. 衰减公式修正

**之前的 bug**：`consciousness`（意识层）在衰减——但意识层是 Connie 的内部行动备忘，按 Living Memory Architecture 的设计不应该衰减。

**修了什么**：
- `memory_service.py` 的 `_decay_rate_for_layer()`：consciousness 返回 0.0（不衰减）
- `scheduler/jobs.py` 的 `decay_memories()`：完全重写，只衰减 long 和 short

**另外去掉了一个多余设计**：arousal 影响衰减速度。Living Memory 的哲学是衰减要简单纯粹，arousal 的影响力应该只在召回时体现，不该干扰衰减。

## 当前记忆系统架构（完整，下一个窗口必读）

### 四层架构

| 层级 | 用途 | 衰减 | 地板值 |
|---|---|---|---|
| `core` | 关系基石（极少用） | 不衰减 | — |
| `long` | 重要事实/偏好/关系事件 | ×0.995/天 | 0.3 |
| `short` | 临时事项/短期上下文 | ×0.95/天 | 0.1 |
| `consciousness` | Connie 内心备忘/自我状态 | 不衰减 | — |

### 写入流程

```
用户发消息
  → 后台异步 extract_candidates()（LLM 提取候选，含 valence/arousal）
  → 候选等待审核（或 Connie 通过 remember 工具直接写入）
  → create_memory()
    → 生成 embedding（BGE-M3）
    → find_associated() 找 top-3 关联旧记忆（用 embedding 余弦相似度）
    → 写入 memory_links
    → 更新关联记忆的 trigger_count
```

### 检索流程（双通道）

```
recall(query)
  → Channel A：关键词精确匹配（tag + content）
  → Channel B：embedding 余弦相似度
  → 合并：max(keyword_score, semantic_score) per memory
  → 加权：× layer_weight × (1 + arousal × 0.3) × memory_weight
  → 已解决任务 × 0.3
  → 40% 随机浮现旧记忆
  → 短期/意识层触发 ≥3 次 → 自动晋升长期
```

### 每晚定时任务

- **衰减**：long ×0.995, short ×0.95（core/consciousness 不动）
- **过期清理**：short 有 expires_at 且到期 → 硬删除
- **去重 digest**（2:30）：LLM 分批扫描，合并真正重复的记忆

### 当前数据

- 正式记忆：~305 条
- 全部有 embedding：317 条（含已删除的）
- 情感标注完成：307 条
- 层级分布：core 极少，long 为主，short/consciousness 少量

## 踩过的坑（重要，别再踩）

### 1. `sqlite3.Row` 没有 `.get()` 方法
Python 的 `sqlite3.Row` 对象不支持 `row.get("key")`，会报 AttributeError。
正确写法：`row["key"] if "key" in row.keys() else None`

### 2. Digest 误删不同记忆
"静儿在学韩语"和"静儿在学法语"被 LLM 当成重复——句式相似但内容完全不同。
已在 `digest.md` 加了明确反例规则。

### 3. SSH 嵌套引号
VPS 上用 `ssh ... "python -c '...'"` 执行 Python 代码时，嵌套引号极易出错。
**推荐用 heredoc**：`ssh ... << 'EOF'`（单引号 EOF 防止本地变量展开）。

### 4. Consciousness 不应衰减
意识层是 Connie 的行动备忘和内心感悟，不是"会忘记"的记忆。只有 long 和 short 需要衰减。

### 5. Arousal 不应影响衰减
arousal 的作用域是"召回时加权"，不是"衰减时减速"。衰减要保持简单：每天乘一个固定系数就完了。
