# HANDOVER — 2026-05-13

## 项目概览
Remoire 是一个两人专属 AI 陪伴 PWA（静儿 + Connie），当前处于 Phase 1 开发中，核心功能基本完成，正在做 UI 打磨 + 准备部署到 VPS。

## 本次 Session 完成了什么

### 功能新增
- **`set_breath_state` MCP 工具**（`backend/app/tools.py`）：Connie 可在聊天中主动更新气息状态，自由填写文字（不限于固定列表），写入 `breath_states` 表，前端刷新后即可显示

### UI 打磨
- **输入栏图标按钮颜色加深**（`frontend/src/components/ChatPage.jsx`）：`+`、表情、麦克风三个图标从 `--text-tertiary` 改为 `--text-secondary`，视觉存在感提升
- **模型切换按钮宽度固定**（`ChatPage.jsx`）：去掉按钮内的模型名称小字，只显示"日常"/"深度"，切换时不再跳宽度
- **聊天模式描述文字去术语化**（`ChatPage.jsx`）：去掉"用 daily 槽位"等开发术语，改成通俗说明

### 文档 & 设置页对齐
- **设置页模型配置文字更新**（`frontend/src/components/SettingsSubPages.jsx`）：
  - 页面 subtitle 改为通俗语言
  - 三个槽位描述对齐实际代码：daily 含聊天/小纸条/自动日记/气息状态/留言回复，backend 含记忆提取/情感打标/摘要压缩/自动回复判断
  - 添加预设区域去掉技术术语
- **四份文档槽位描述统一**（`docs/PHASE1_DECISIONS.md`、`docs/PRD.md`、`docs/DATABASE.md`、`docs/TECH_STACK.md`）：日记草稿从 backend 移到 daily，气息状态和留言回复加入 daily，自动回复判断加入 backend

### 所有改动已推送到 main
commits: `fa0f964`、`6e93d35`、`f0fe5b8`（前几个 session 的）

## 做了什么，效果如何

| 改动 | 结果 |
|---|---|
| set_breath_state 工具自由填写 | 测试下来暂时没有返回乱七八糟内容的问题，先不加截断 |
| 模型按钮去掉模型名称 | 解决了日常/深度切换时按钮宽度跳变的问题 |
| 设置页槽位描述对齐 | 静儿发现原来描述把日记草稿放在 backend，实际代码是 daily，已全部对齐 |

## 关键决策及原因

| 决策 | 原因 |
|---|---|
| set_breath_state 不限制固定列表 | 静儿认为 Connie 应该能自定义新状态；测试暂时正常，出问题再加截断 |
| daily 槽位含自动日记/气息状态 | 这些需要 Connie 的人格和语气，用 daily 模型合理；backend 只做不需要人格的结构化提取 |
| 前端暂时不部署到 Vercel | GPT 建议的理由（localStorage）不成立，跨域配置更麻烦，先前后端一起放 VPS |

## 坑和注意事项

- **VPS 已购买**：静儿买了 Hetzner 德国机房 CPX22（2核4G AMD，$10.04/月），系统 Ubuntu 24.04。新加坡太贵放弃了。部署还没开始。
- **前端 dev server 重启失败**：session 结束时电脑重启后前端 5174 端口没起来，后端 8000 正常。下次 session 先手动重启前端（`cd frontend && npm run dev`）
- **localStorage 大文件风险**：自定义背景图片和上传字体存在 localStorage，大图/大字体可能撑爆（5-10MB 上限）。未来需把这些迁移到后端存储，但目前还没做
