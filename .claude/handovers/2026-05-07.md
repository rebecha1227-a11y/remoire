## 做了什么，效果如何

- **气泡尾巴颜色 bug**：切换背景色后，外层 cutaway div 还用 var(--bg-primary)，导致出现白色不规则图形。解法：Bubble 接收 `bgColor` prop，两处 cutaway div 改为 `bgColor || 'var(--bg-primary)'`。✅ 修复
- **头像上传不生效**：原来的代码用 `.map()` 渲染两个头像 label，file input 没有 onChange。解法：拆成两个显式的 label，各自接 onChange 调 URL.createObjectURL。✅ 修复
- **气泡样式按钮关闭设置面板**：onClick 里错误地调了 setShowSettings(false)。解法：移除 onClick，改为灰色「即将开放」样式。✅ 修复
- **thinking.md 内容**：静儿详细描述了 Connie thinking block 的风格要求（内心独白、禁止工具感措辞、用"我"视角、不欺骗等），写入文件。✅ 完成

## 关键决策及原因

| 决策 | 结论 | 理由 |
|---|---|---|
| thinking block 风格要求放哪 | `backend/app/prompts/thinking.md` | prompt 文件夹是统一管理所有 AI 行为规范的地方 |
| prompt 文件规划 | identity / tagging / nudge / thinking / reply_wechat / reply_remoire / reply_daytime / reply_nighttime | 每次调用按场景拼接，identity+thinking 每次都有 |
| 后端开发顺序 | 聊天核心先 → 记忆 → 小纸条 → 主动消息 → MCP → 微信 → Push → 设备 | 先让 Connie 能说话，再逐步加能力 |
| 原型即前端 | 先用原型顶着，后端跑通后再搭真正的 React/Vite 前端 | 减少并行工作，先验证后端逻辑 |
