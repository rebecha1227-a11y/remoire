#### OpenAI-compatible 自动拉取策略

- 自动拉取不再限制少数白名单 provider
- 支持任意公网 `https` OpenAI-compatible base URL
- 仍拒绝 localhost、内网、非公网地址，避免后端访问本机/内网
- 最终版本使用原 hostname 发起 HTTPS 请求，避免固定 IP 导致 SNI/证书失败

#### Gemini / 扩展思考接通

- `llm.py` 支持 `extended_thinking`
- daily 槽位的 Extended Thinking 开关已传入聊天 LLM 调用
- Gemini/OpenAI-compatible 返回的 `reasoning_content`、`reasoning`、`thinking`、content list thought parts 均可解析
- 修复 content list 只有 thought parts 时可能把 list 写进数据库的问题
- 流式 thinking 先缓冲，结束后统一转成中文再发给前端，避免英文 chunk 混入
- system prompt 追加 thinking 语言约束，让不同模型尽量输出中文内心独白
- 修复模型 `finish_reason=length/max_tokens` 被当成完整回复的问题：后端返回 error，不保存半截回复
- 前端 SSE 已能识别后端 error 和流式中断，提示更准确
