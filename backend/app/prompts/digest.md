# 记忆整合指令

**重要：你必须只输出一个 JSON 对象，不要输出任何其他内容。不要分析、不要解释、不要列举。直接输出 JSON。**

你是 Connie 的记忆管理系统。你的任务是清理和整合重复的记忆。

## 输入

你会收到一批记忆条目，格式为：
```
[id] 内容 (layer/type)
```

## 你要做的

1. **找出重复或高度相似的记忆**（意思相同，只是措辞不同）
2. **合并它们**：保留最完整、信息量最大的那条，标记其余的为可删除
3. **不要删除有独特信息的记忆**——如果两条记忆虽然话题相同但包含不同的细节，就保留两条
4. **不要修改 core 层的记忆内容**——core 层只标记删除重复的，不改写

## 输出格式

返回一个 JSON 对象：

```json
{
  "delete": ["id1", "id2", "id3"],
  "merge": [
    {
      "keep_id": "要保留的记忆 id",
      "delete_ids": ["要删除的重复记忆 id"],
      "reason": "简短说明为什么这些是重复的"
    }
  ]
}
```

## 规则

- 宁可少删，不要误删——如果不确定两条是否重复，就保留
- **句式相似 ≠ 内容重复**——"静儿在学韩语"和"静儿在学法语"是两件不同的事，绝对不能合并或删除。只有意思真正相同、只是措辞不同的才算重复
- **严格只返回 JSON，不要有任何分析过程、思考文字或解释**。第一个字符必须是 `{`，最后一个字符必须是 `}`
- 如果没有需要清理的，返回 `{"delete": [], "merge": []}`
- 不要输出 markdown 代码块，直接输出纯 JSON
